Build Rethinksoft, a marketplace of launch-ready software businesses. The core promise is: Pick it. Own it. Start selling.

Customers browse complete commercial applications such as an AI Resume Builder, AI Interview Coach, AI Content Studio, AI Lead Finder, and Niche Job Board. Every founding product includes a public website, web application, admin panel, authentication, database, payments, documentation, and deployment path.

Offer two ownership paths. Rethink Cloud lets customers add their brand, domain, pricing, and connected Stripe account while Rethinksoft manages hosting, deployment, updates, monitoring, and backups. Source Code gives customers the complete application, commercial-use rights, documentation, and freedom to modify and self-host it. Never add hidden revenue tracking to downloaded code.

Structure the customer journey as Pick, Own, Launch, Sell, Grow. Use Stripe Connect for managed commerce instead of asking customers to paste secret Stripe keys. Clearly disclose any cloud transaction fee.

Use hybrid pricing. Sell software licenses for $199 to $499 one time. Offer optional Rethink Cloud from $29 per month and Rethink Growth from $299 per month. Growth services can include SEO, AEO, content, social media, outreach, lead generation, and paid acquisition.

Keep the existing free research layer: product-market directory, public agent prompts, open source foundations, community builds, and useful free tools. Treat those resources as the discovery engine that leads founders toward a launch-ready business.

Stack: Astro server output with the Node adapter and better-sqlite3. Use server-rendered HTML and vanilla JavaScript, with no client framework. Keep the warm white, orange, and ink visual system, simple Manrope typography, responsive layouts, accessible interactions, tasteful motion, and prefers-reduced-motion support.

Store each researched market as JSON in data/apps. Keep SQLite-backed waitlist, community submissions, dedupe, honeypots, and IP rate limits. Include canonical URLs, sitemap.xml, robots.txt, JSON-LD, and build-time Open Graph images using satori and resvg.

MIT license. Public repository. No accounts until the product requires them. No third-party tracking. Make software entrepreneurship accessible to more people without pretending that launching a business is effortless.
